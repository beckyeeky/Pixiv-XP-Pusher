# Do not double-count character and copyright affinity

When a work matches both Character and Copyright preferences, its Identity Contribution is the greater of those two typed contributions rather than their sum. Character and source-work tags naturally co-occur, so summing them would reward the same underlying identity signal twice and let identity-heavy works overwhelm transferable Feature preferences. This sacrifices some reinforcement from independently learned Character and Copyright affinity in exchange for more stable comparison between Identity and Feature contributions.
