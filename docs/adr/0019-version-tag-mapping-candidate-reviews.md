# Version Tag Mapping Candidate reviews instead of reopening them

When a rejected Tag Mapping Candidate receives materially changed semantic evidence, proposal provenance, or merge principles, create a new candidate revision linked to the rejected record instead of reopening or overwriting the old review. Unchanged evidence must not trigger another model call. This preserves the human decision audit trail and makes later reconsideration explicit, at the cost of storing multiple linked revisions for the same unordered tag pair.
