# Require human acceptance for Tag Aliases

Only a human-accepted Tag Alias may merge a raw tag into another Normalized Tag, while a Search Alias may improve retrieval without changing identity. Deterministic spelling normalization remains allowed, but semantic inference and automatic models may only propose Tag Mapping Candidates, which have no runtime effect; the former `AITagProcessor`, IP alias, `ai_tag_cache`, and `tag_mapping_stats` paths are quarantined because they mixed filtering, synonym inference, profile rewriting, and search feedback without the Grounded Judge or human-review guarantees used elsewhere. Existing legacy rows are retained as reviewable history rather than activated or deleted, trading immediate reuse for stable global identity and reversible migration.
